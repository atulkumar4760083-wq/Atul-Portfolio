# Atul Kumar Yadav - Developer Portfolio Website

A modern, responsive, and interactive developer portfolio website built using **HTML5, CSS3, and JavaScript**.

---

1. **Modern Dark & Light Mode**:

   - Direct LinkedIn connection.

## 🚀 How to Run Locally

### Option 1: Direct File Opening
Double-click `index.html` or right-click and choose **Open with Chrome / Edge / Firefox**.

### Option 2: Local HTTP Server (Python)
In the portfolio directory, run:
```bash
python -m http.server 8080
```
Then open [http://localhost:8080](http://localhost:8080) in your browser.
